Designer l'MVP qu'un investisseur peut tester.

Mission freelance pour Eximion — MVP d'une plateforme d'investissement crypto destinée à sécuriser une levée de fonds. Cible mixte : investisseurs (preuve de scalabilité et de market potential), early adopters (validation usability), équipe produit, stakeholders.

Product Designer freelance. Périmètre complet : cadrage des fonctionnalités MVP, design system fondateur (UI Kit), première identité de marque (logo, branding).

Mon rôle

Product Designer freelance

Mission solo de bout en bout — cadrage produit MVP, design system fondateur, première identité de marque.

Enjeu : faire passer Eximion du pitch deck au MVP testable, dans un contexte crypto post-FTX où chaque détail compte pour rassurer un investisseur. Trois livrables imbriqués : produit, système, marque.

  • Produit — cadrage des fonctionnalités fondatrices : Home Page avec Dashboard (KPIs, transactions récentes), Withdrawal, Deposit, User Settings.
  • Design system — Platform UI Kit Fundamentals : typographie, palette, iconographie, espacement, composants réutilisables. Base scalable, livrée dès la V1.
  • Marque — premier logo Eximion, palette, ton visuel, base d'expansion pour la suite produit post-levée.

Ce que je n'ai pas fait : le code, la stratégie financière / trading, la sélection des actifs crypto listés, le pitch investisseur lui-même.

Trois décisions

Les arbitrages qui ont façonné l'MVP

  1. 01

    Scope MVP serré sur quatre surfaces fondamentales

    Tentation classique pour un MVP destiné à la levée : empiler les fonctionnalités pour impressionner. Mais un investisseur teste la profondeur, pas la surface — vaut mieux quatre écrans qui marchent vraiment que douze demi-finis.

    J'ai cadré quatre surfaces critiques : Dashboard (KPIs + transactions récentes), Withdrawal, Deposit, User Settings. Trade-off assumé : pas de trading avancé, pas de social, pas d'alertes en V1. Bénéfice : flow démontrable bout en bout, sentiment de produit fini, validation usability immédiate auprès des early adopters.

  2. 02

    Design system dès le MVP, pas après la levée

    Tentation : design ad-hoc pour aller vite, « on refera propre après la levée ». Risque : dette de design immédiate, refonte douloureuse post-levée — exactement au moment où il faut accélérer pour tenir la promesse faite aux investisseurs.

    J'ai investi dans le Platform UI Kit Fundamentals dès la V1 : typo, palette, iconographie, espacement, composants réutilisables. Coût : deux à trois semaines de design en amont. Bénéfice : cohérence visible dans le deck, scalabilité du produit, fondation propre pour la croissance — et signal de maturité produit pour les investisseurs.

  3. 03

    Identité de marque en parallèle du produit, pas après

    Choix possible : partir d'un nom placeholder, designer l'identité après la levée. Mais pour un investisseur, l'identité visuelle est un signal : cohérence marque ↔ produit = maturité d'équipe, capacité à exécuter sur le long terme.

    J'ai designé le premier logo Eximion et l'identité de marque (palette, ton, valeurs visuelles) en parallèle des écrans produit. Bénéfice : cohérence parfaite produit ↔ marque dans le pitch deck, base solide pour l'expansion post-levée, identité reconnaissable dès le jour 1.

Impact

Ce que ça a livré

  • MVP livré sur quatre surfaces fondamentales (Dashboard, Withdrawal, Deposit, Settings) — testable bout en bout par investisseurs et early adopters.
  • Platform UI Kit Fundamentals : typo, palette, iconographie, espacement, composants — base scalable prête pour la croissance post-levée.
  • Première identité Eximion : logo, palette, ton visuel — cohérence marque ↔ produit assurée dans le deck.
  • Collaboration design ↔ développement structurée : système de composants partagés, livrables prêts à intégration.
